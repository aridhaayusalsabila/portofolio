# Aridha Ayu Salsabila — Portfolio

A responsive personal portfolio built with semantic HTML, modern CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser or serve the repository root with any static file server. No build step or package installation is required.

## Contact form

The inquiry form validates its required fields and opens a prefilled email in the visitor's default mail app. It does not submit data to a backend.
